Build a Recipe Page

Build an app that is functionally similar to this example project. Try not to copy the example project, give it your own personal style.

Objective: Fulfill the user stories below and get all the tests to pass to complete the lab.

User Stories:

  1. You should have a !DOCTYPE html declaration.
  2. You should have an html element with lang set to en.
  3. You should have a head element containing a title element with the name of your recipe, and a meta element with a charset attribute set to UTF-8.
  4. You should have a body element.
  5. You should have only one h1 element with the name of your recipe.
  6. You should have a p element that introduces the recipe below the h1.
  7. You should have one h2 element with the text Ingredients for the ingredients section.
  8. You should have an unordered list (ul element) with at least four list items (li elements) that lists your ingredients below the first h2 element.
  9. You should have a second h2 element with the text Instructions for the instructions section.
  10. You should have an ordered list (ol element) with at least four list items that lists the recipe steps in order, below the second h2.
  11. You should have one img element with a src attribute set to a valid image and an alt attribute describing the image. You can use https://cdn.freecodecamp.org/curriculum/labs/recipe.jpg if you would like.

Tests:

  • Passed: 1. Your recipe page should have a !DOCTYPE html declaration.
  • Passed: 2. You should have an html element with lang set to en.
  • Passed: 3. Your html element should have a closing tag. Closing tags have a / just after the < character.
  • Passed: 4. You should have a head element within the html element.
  • Passed: 5. Your head element should have a closing tag. Closing tags have a / just after the < character.
  • Passed: 6. You should have a title element within your head element.
  • Passed: 7. Your title element should have a closing tag. Closing tags have a / just after the < character.
  • Passed: 8. Your title element should have your recipe title.
  • Passed: 9. You should have a meta element within your head element.
  • Passed: 10. Your meta element should have its charset attribute set to UTF-8.
  • Passed: 11. You should have a body element within your html element.
  • Passed: 12. Your body element should have a closing tag. Closing tags have a / just after the < character.
  • Passed: 13. You should have only one h1 element with the name of your recipe.
  • Passed: 14. You should only have one h1 element.
  • Passed: 15. You should have a p element below your h1 element.
  • Passed: 16. Your first p element should describe your recipe.
  • Passed: 17. Your first h2 element should have the text Ingredients.
  • Passed: 18. You should have an unordered list element below your first h2 element.
  • Passed: 19. You should have at least four list item elements in your unordered list with the ingredients.
  • Passed: 20. Your second h2 element should have the text Instructions.
  • Passed: 21. You should have an ordered list element below your second h2 element.
  • Passed: 22. You should have at least four list item elements in your ordered list with the instructions.
  • Passed: 23. You should have at least one img element.
  • Passed: 24. All your img elements should have a valid src attribute and value.
  • Passed: 25. All your img elements should have an alt attribute to describe the image.
